# TRUSTEE Anti-Phishing Domain Monitoring & Re-Check System

Система проактивного виявлення, інтелектуального скорингу та моніторингу потенційно фішингових доменів, які імітують сервіси **TRUSTEE** (`trustee.io`, Trustee Plus, Trustee Wallet).

Розроблено відповідно до технічних вимог та узгодженого scope для екосистеми TRUSTEE.

---

## 🚀 Основний функціонал

1. **Генератор мутацій бренду (Permutation Engine):**
   - **Гомогліфи (Punycode / IDN):** виявлення використання кириличних літер-двійників (`е`, `о`, `а`, `с`) для маскування під латиницю (`xn--...`).
   - **Тайпосквотинг:** помилки набору, пропуски, перестановки літер (`truste.io`, `trutsee.io`).
   - **Комбосквотинг:** поєднання бренду з цільовими векторами атак (`-wallet`, `-plus`, `-card`, `-login`, `-restore`, `-apk`, `-support`, `-bonus`).
   - **TLD-матриця:** перевірка популярних зон (`.com`, `.net`, `.org`, `.app`, `.xyz`, `.top`, `.online`, `.cc`, `.io`).

2. **Постійний моніторинг CertStream (Real-time):**
   - Асинхронне прослуховування глобального потоку випуску нових SSL-сертифікатів.
   - Виявлення фішингових ресурсів за 1–3 секунди після генерації сертифіката (ще до їх появи в пошуковиках).

3. **DNS & MX фільтрація:**
   - Асинхронне відсіювання мертвих зон (A / AAAA записи).
   - Детекція налаштованих поштових серверів (MX-записи за відсутності сайту = високий ризик Email Spoofing).

4. **Глибокий контентний сканер (Deep Inspection):**
   - Аналіз SSL-сертифіката (емітент, вік у днях).
   - Детекція паркувальних заглушок реєстраторів (Sedo, GoDaddy тощо).
   - Пошук критичних крипто-маркерів: форми викрадення сід-фраз (`12 words`, `mnemonic`, `seed phrase`), запити приватних ключів, фейкові кнопки завантаження APK.

5. **Інтелектуальний Risk Scoring (0–100):**
   - Відокремлює реальний крипто-фішинг від семантичного шуму (наприклад, англомовні юридичні компанії зі словом "trustee").
   - Категоризація: `CRITICAL` (80–100), `HIGH / SUSPICIOUS` (60–79), `DORMANT` (30–59), `CLEAN` (<30).

6. **Збереження повної історії перевірок у PostgreSQL:**
   - Таблиця `domains`: поточний статус та найактуальніший бал.
   - Таблиця `domain_checks`: повна хронологія кожного сканування (таймстемп, IP, HTTP-код, SSL, знайдені тригери).

7. **Функція Re-check (Відстеження динаміки змін стану):**
   - Точкова перевірка домену з виведенням повної хронології перевірок у консоль.
   - Фоновий перескан "dormant"-доменів (чи не активував зловмисник фішинг на раніше сплячому домені).

8. **Telegram-алертинг:**
   - Миттєві сповіщення про нові загрози високого ступеня ризику (Score >= 60) та сповіщення про зміну стану домену.

## 🛠️ Встановлення та запуск

### 1. Вимоги
- Python 3.11+
- PostgreSQL 14+ (локальний або через Docker)

### 2. Встановлення залежностей
```bash
pip install -r requirements.txt
```

### 3. Налаштування оточення (.env)
Створіть файл `.env` на основі `.env.example`:
```env
# Рядок підключення до PostgreSQL
DATABASE_URL=postgresql+asyncpg://postgres:postgres@localhost:5432/trustee_antifish

# Telegram бот (опціонально: якщо не вказано, алерти виводяться в консоль)
TELEGRAM_BOT_TOKEN=
TELEGRAM_CHAT_ID=

# Поріг сповіщень
MIN_ALERT_SCORE=60
```

> **Запуск PostgreSQL через Docker (найшвидший спосіб):**
> ```bash
> docker compose up -d
> ```

## 💻 Використання (CLI команди)

### 1. Ініціалізація бази даних
Створює всі необхідні таблиці та індекси в PostgreSQL:
```bash
python main.py --init-db
```

### 2. Точкова перевірка та перегляд історії змін домену (Re-check)
Аналізує домен прямо зараз, зберігає новий знімок у базу та виводить повну хронологію змін:
```bash
python main.py --check trustee-wallet-restore.com
```

### 3. Сканування мутацій бренду (Batch Scan)
Генерує тайпо, гомогліфи та комбо-слова навколо Trustee і швидко перевіряє їх:
```bash
# Перевірити 50 мутацій у 10 потоків
python main.py --scan-mutations --count 50 --concurrency 10
```

### 4. Запуск безперервного моніторингу (24/7 Daemon)
Підключається до CertStream і слухає глобальний випуск сертифікатів у реальному часі:
```bash
python main.py --daemon
```

### 5. Повторне сканування сплячих доменів (Dormant Re-check)
Піднімає з бази домени зі статусом `dormant` або `parked` і перевіряє, чи не активували на них фішинг:
```bash
python main.py --recheck-dormant
```

### 6. Перегляд доменів у базі даних (List & Filtering)
Виводить форматовану таблицю доменів з їхнім статусом, ризик-балом та датою останньої перевірки (за замовчуванням виводиться **ТОП-50 найризикованіших**, щоб не засоряти буфер консолі):
```bash
# Переглянути ТОП-50 доменів з бази
python main.py --list

# Переглянути ТОП-20 або ТОП-100 доменів
python main.py --list --limit 20
python main.py --list --limit 100

# Переглянути тільки підозрілі домени або активний фішинг
python main.py --list --status suspicious
python main.py --list --status active_phishing
```
